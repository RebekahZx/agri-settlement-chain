# Data

`all_india_crop_area_production_yield_2021-22_to_2025-26.csv` contains
all-India crop-wise area, production and yield estimates by crop and season
(Kharif / Rabi / Summer / Total) for 2021-22 through 2025-26. Empty cells
mean no value was reported for that season and year. 2025-26 is only
partly populated.

It provides context for the produce types used in the settlement experiments
(wheat, rice, maize, soybean, barley). The contract and experiment scripts
do not read it.

Source: Government of India all-India crop production estimates.
